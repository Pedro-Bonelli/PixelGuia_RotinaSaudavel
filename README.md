# Pixel Guia — landing page de rotina saudável

Página estática de apresentação do produto digital “40 Dias: O Protocolo Prático + Sistema de Gestão Metabólica”, com imagens em `imgs/` e conteúdo em `index.html`.

## Estrutura

- `index.html` (ou o caminho indicado abaixo): página inicial.
- Arquivos HTML adicionais: páginas internas, quando presentes.
- Pastas de estilos, scripts e imagens: apresentação e recursos visuais.

## Como executar

Abra o projeto no VS Code e visualize o arquivo HTML indicado com Live Server ou diretamente no navegador.

```bash
git clone https://github.com/Pedro-Bonelli/PixelGuia_RotinaSaudavel.git
cd PixelGuia_RotinaSaudavel
```

Ponto de entrada: `index.html`. Não há etapa de instalação de pacotes na raiz.

## Observações

O repositório contém a página de apresentação; não há backend ou sistema de pagamento identificado na raiz.
